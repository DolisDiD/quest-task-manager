# 🚨 СРОЧНО: Создание bucket'а 'cards' в Supabase

## ❌ ПРОБЛЕМА
В вашем Supabase проекте не настроено ни одного bucket'а для хранения изображений карточек.

## ✅ РЕШЕНИЕ

### ШАГ 1: Откройте Supabase Dashboard
1. Перейдите на [https://supabase.com/dashboard](https://supabase.com/dashboard)
2. Войдите в свой аккаунт
3. Выберите ваш проект

### ШАГ 2: Создайте bucket 'cards'
1. В левом меню нажмите **"Storage"**
2. Нажмите **"Buckets"**
3. Нажмите **"New bucket"** (синяя кнопка)

### ШАГ 3: Настройте bucket
Заполните поля:
- **Name**: `cards`
- **Public bucket**: ✅ **ВКЛЮЧИТЕ** (важно!)
- **File size limit**: `5 MB`
- **Allowed MIME types**: `image/jpeg, image/png, image/webp, image/gif`

### ШАГ 4: Создайте bucket
1. Нажмите **"Create bucket"**
2. Дождитесь создания

### ШАГ 5: Проверьте результат
1. В списке bucket'ов должен появиться `cards`
2. Убедитесь, что он помечен как **Public**

## 🧪 ТЕСТИРОВАНИЕ
1. Обновите страницу приложения (Ctrl+F5)
2. Попробуйте загрузить изображение для карточки
3. Если все работает - проблема решена!

## 📞 ЕСЛИ НЕ ПОЛУЧАЕТСЯ
Если у вас нет доступа к Supabase Dashboard или возникают проблемы:
1. Обратитесь к администратору проекта
2. Или создайте новый Supabase проект с правильными настройками

## 🔍 АЛЬТЕРНАТИВА: Через SQL
Если у вас есть доступ к SQL Editor:
1. Откройте **SQL Editor** в Supabase Dashboard
2. Выполните скрипт `check_and_create_bucket.sql`
